The big idea

A program is a recipe for the computer

A recipe is a list of steps, in order, that a cook follows exactly. A cook can guess what “a pinch of salt” means. A computer cannot guess anything.

🍳

Recipe

Steps written for a cook. If a step is missing, the dish fails.

📜

Program

Steps written for a computer. If a step is wrong or missing, the program fails.

✍️

Programming

Writing those steps clearly, one by one, in a language the computer can be taught — like C++.

The compiler is like a translator between you and a person who only speaks 0s and 1s. If your sentence has a spelling mistake, the translator stops and tells you: that message is a compile error.

Our first program

Hello, World! — line by line

Press → to walk through the code. Each line lights up with its meaning.

  1. #include <iostream> — “Bring in the input/output toolbox.” Without it, the computer has never heard of cout. The # line is read by the preprocessor before compiling.
  2. using namespace std; — The tools in that toolbox live in a drawer named std. This line says “open that drawer for me”, so we can write cout instead of std::cout.
  3. int main() — Every program starts here. main is the main gate of the program. The int means: when finished, it hands back a whole number to the operating system.
  4. { … } — Curly braces mark the body of main. Everything between { and } belongs to it, like the walls of a room.
  5. cout << "Hello, C++!"; — “Send this text to the screen.” Text inside double quotes is printed exactly as written. The ; at the end is the full stop of a statement.
  6. return 0; — Tells the operating system “I finished successfully.” By convention 0 means success.
Remember this shape

Every C++ program is a sandwich

🍞

Top bread

Headers. #include lines that bring in tools.

🫓

Filling

main() with { }. The statements that actually do the work, each ending with ;

🍞

Bottom bread

return 0; then the closing }. A clean finish.

Two compilers, one language

The same program, written two ways

red = only in Turbo C++  ·  green = only in Modern C++. Both print exactly the same thing.

Important

Online compilers and modern IDEs reject the Turbo version. Turbo C++ rejects some modern code too. So always know which compiler you are using.

Spot the differences

Turbo → Modern: 5 changes

#Turbo C++Modern C++Why it changed
1#include <iostream.h>#include <iostream>The standard removed .h from C++ headers.
2(nothing)using namespace std;Standard tools now live inside the std drawer; you must open it.
3void main()int main()The standard says main must return an int (a whole number).
4(nothing)return 0;Reports “success”. (If missing in main, modern C++ assumes it.)

Memory trick

Turbo → Modern: drop the .h, add std, make main an int.

Input and output

cout speaks. cin listens.

cout << data;

console out — the computer speaks to you.

Data flows into the screen. The arrows point at cout.

cin >> variable;

console in — you speak to the computer.

Data flows out of the keyboard into the variable. The arrows point at the variable.

The arrows always point in the direction the data travels.

<< is called the insertion operator and >> the extraction operator — you will study them properly in Lesson 6.

Output

Printing text, numbers, and answers

  1. Text + endl. The text in quotes is printed as-is. endl means “end of line”: move the cursor to a new line, like pressing Enter.
  2. Chaining with <<. You can print several things in one statement: first the text "Age: ", then the number 16, then endl. Numbers do not need quotes.
  3. Text vs calculation. "5 + 2 = " is inside quotes, so it is just text. But 5 + 2 is outside the quotes, so the computer calculates it and prints 7.

Input

Asking the user: add two numbers

  1. Reserve three lockers. int a, b, sum; asks the computer for three boxes that can each hold a whole number. They are empty (garbage) for now.
  2. Prompt. A friendly message so the user knows what to type.
  3. cin >> a >> b; The program waits for the keyboard. If the user types 5 7, the 5 goes into a and the 7 goes into b. Separate values with a space or Enter.
  4. Assignment. = does not mean “equals” here. It means: calculate the right side, then store it in the left side. So sum becomes 5 + 7 = 12.
  5. Show the result. "Sum = " is text; sum (no quotes!) is the variable, so its value 12 is printed.

The sample run shows the user typing 5 7 after the prompt.

Notes for humans

Comments: the compiler ignores them

Comments explain why the code does something. They are for you, your teacher and anyone who reads the program later.

// text

Single-line. Everything to the right, until the end of the line, is ignored.

/* text */

Multi-line. Starts at /* and ends at the first */. They cannot be nested.

Pro tip: put // before a line of code to temporarily “switch it off” while testing.

Debugging game

Find the 3 bugs in this program

  1. Bug 1: Main must be main. C++ is case-sensitive: Main and main are different words.
  2. Bug 2: Cout must be cout. Same reason: capital C is a different name.
  3. Bug 3: the statement cout << "Hello" has no ; at the end. The compiler complains on the next line, which is confusing — always check the line before the reported error.
The usual suspects

1) wrong capital letter  2) missing ;  3) missing closing " or }  4) forgot #include / using namespace std;
