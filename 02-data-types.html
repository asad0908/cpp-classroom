Data Types

Before the computer stores anything, it must know what kind of data it is and how much room to keep for it.

By the end of this lesson you can
  • name every built-in type and pick the right one for a job
  • quote the size of each type in Turbo C++ and Modern C++ using one trick
  • use modifiers (signed, unsigned, short, long), bool, void and sizeof
The big idea

Every kind of thing needs the right container

In a kitchen, you do not store water in a paper bag, or a single grain of salt in a huge drum. Memory works the same way.

📏

1. How much room?

A tiny number needs a small box, a giant number needs a big one.

🔑

2. Which values?

A box for whole numbers cannot hold 3.5. A box for letters cannot hold 42.

🧮

3. Which operations?

You can add two numbers. Adding two letters makes no sense.

A data type = size + allowed values + allowed operations

Careful

'A' (single quotes) is a char. "A" (double quotes) is a string. Also: Turbo C++ 3.0 has no bool — there you use int with 1 / 0.

How much room?

Memory is a long row of tiny boxes called bytes

A bigger type books more boxes — like booking seats in a cinema: char books 1 seat, double books 8.

Memory trick

Never forget a size again

char 1 → short 2 → int & float 4 → double 8

Each step doubles

1, 2, 4, 8 … and long double doubles once more to 16.

float is half of double

That is why it is less accurate: half the room, half the digits.

Turbo’s odd one out

int is 2, the same as short, because Turbo C++ was built for old 16-bit DOS computers.

The standard guarantees only char = 1 and short ≤ int ≤ long. Real sizes depend on the compiler and machine — so we ask the compiler with sizeof.

Try it

sizeof tells the truth about your compiler

  1. sizeof(type) is an operator that returns how many bytes a type occupies. It works on a type name, like sizeof(char), or on a variable.
  2. int prints 4 on a modern compiler but 2 in Turbo C++. Click the Turbo C++ tab and press Run to see the old output.
  3. long is 8 on 64-bit Linux and most online compilers, but 4 on Windows. long long always gives 8 and does not exist in Turbo C++.
  4. long double is 16 here, 10 in Turbo C++, and can also be 12 or 8 on other systems.
  5. bool takes 1 byte (even though it only needs 1 bit). Turbo C++ 3.0 has no bool, so that line is missing from the old program.

Output shown is from a typical 64-bit Linux online compiler; the Turbo tab shows the 16-bit result.

Think first

What do these print?

3.5 → 8

A decimal number written plainly is a double by default.

3.5f → 4

The f suffix turns it into a float.

'A' → 1

A single character is a char: 1 byte.

Tuning a type

Modifiers change the size or the range

Think of modifiers as adjectives: a long int, an unsigned int.

±

signed / unsigned

Can the value be negative?

signed (the default): negative, zero and positive.

unsigned: zero and positive only — but it reaches twice as high.

↕

short / long

Make the box smaller or bigger.

short int, long int, long long, long double.

int can be dropped: long means long int.

Range formula — never memorise ranges again

n bits →   signed: −2n−1 … 2n−1−1    unsigned: 0 … 2n−1

Example: char = 1 byte = 8 bits = 28 = 256 patterns. Unsigned: 0…255. Signed: half go negative → −128…127. Turbo’s int = 16 bits → −32768…32767 (unsigned 0…65535).

What if we go past the maximum?

Types wrap around like a car odometer

Picture it

A 5-digit odometer shows 99999. Drive one more kilometre and it shows 00000. A data type does the same when you add past its maximum.

Why -32768?

32767 is the largest short. Adding 1 overflows, and the value wraps round to the smallest one. Bigger data type = bigger range = later wrap. Choose a type large enough for your data.

Let the compiler tell us

Printing the minimum and maximum values

Header names differ too: Turbo <limits.h> → Modern <climits>. Rule: C headers lose the .h and gain a c in front. Press Run to compare the two outputs.

Trick

Decimal types

float vs double: how many digits are correct?

Look closely

Both should be 0.3333… forever. The float goes wrong after about 7 digits (0.333333343…). The double stays right for about 15 digits.

setprecision(15) asks cout to show 15 digits. By default cout shows only 6 significant digits. Turbo’s header is <iomanip.h>, Modern’s is <iomanip>.

Two special types

bool is a light switch. void is an empty hand.

💡

bool

Only two states: true (stored as 1) or false (stored as 0).

cout prints 1 or 0, unless you add boolalpha. Any non-zero value turns into true.

✋

void

“No value.” A function that only does something (like printing) and hands nothing back is void. That is why Turbo C++ allows void main().

You cannot create a variable of type void.

What we learned

✅ Types & sizes

  • Type = size + allowed values + operations.
  • 1 · 2 · 4 · 8: char, short, int/float, double.
  • Turbo: int = 2, long double = 10. Modern: 4 and 16.

✅ Ranges & tools

  • Range: signed −2n−1…2n−1−1, unsigned 0…2n−1.
  • bool = 1/0, void = nothing.
  • sizeof asks the compiler for the real size.
