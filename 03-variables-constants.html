Variables & Constants

Variables are the memory of a program. Constants are the things that must never change.

By the end of this lesson you can
  • declare, initialise and change a variable
  • tell instantly whether a variable name is legal
  • write integer (decimal / octal / hex), floating-point, character and string constants
  • create named constants with #define, const and enum
The big idea

A variable is a labelled locker in memory

Name

The label on the locker: age.

Type

The size and kind of locker: int.

Value

What is inside right now: 16.

Address

The locker number in memory: 1000.

Why “variable”?

You can open the locker and replace what is inside. The locker stays, only the content varies. (Addresses above are only for illustration.)

Life of a variable

Three steps: declare, initialise, assign

1. Declare

“Reserve a locker.”

int age;

2. Initialise

“Reserve and put the first value in.”

int age = 16;

3. Assign

“Replace the value.”

age = 17;

Danger

A variable that is declared but never given a value holds garbage left over from earlier. Always initialise your variables.

See it work

Declaring and changing variables

  1. Declare + initialise. A locker named age that holds whole numbers is created and 16 is put inside.
  2. More lockers. height holds a decimal, grade holds one character (single quotes!).
  3. Printing. We print the values inside the lockers, not the names. " " is a space between them.
  4. Assign. age = 17; throws out the old 16 and stores 17. No type is written this time — the locker already exists.
  5. Result. The second print shows 17. The old value is gone for ever.
Identifiers

The naming rules

✅ Allowed

  • Letters a–z, A–Z
  • Digits 0–9 (but not first)
  • Underscore _

❌ Not allowed

  • Starting with a digit
  • Spaces or symbols: @ # - % $ .
  • Keywords such as int, class, float
First: Letter or Underscore. After that: Letters, Underscores, Digits.  (L-U-D)

And remember: C++ is case-sensitive. Age, age and AGE are three different lockers.

Constants

A constant never changes

Picture it

Your date of birth and the value of π never change. A variable is a locker you can refill. A constant is a locker that is welded shut after the first value goes in.

Literal constants

The value itself, written right in the code.

25   3.14   'A'   "Hello"

Named constants

A name attached to a value that cannot change.

#define   const   enum

Numerical constants

One number, three ways to write it

The prefix tells the compiler which number system you mean. All of these are the value seventy-five.

Classic trap

010 is 8, not ten! A leading zero means octal. And 089 is an error, because 8 and 9 do not exist in octal.

Suffixes: U unsigned, L long, UL, LL long long: 100U, 5000000000LL.

Memory trick

Octal and hex from binary in seconds

Hex digit = 4 bits  ·  Octal digit = 3 bits

Worked example: 75

75 in binary is 1001011  (64 + 8 + 2 + 1).

Hex: group by 4 from the right

100 | 1011 → 4 and B → 0x4B

Octal: group by 3 from the right

1 | 001 | 011 → 1, 1, 3 → 0113

Hex digits

A = 10   B = 11   C = 12   D = 13   E = 14   F = 15

Check: 0x4B = 4×16 + 11 = 75 ✓

See it work

Same value, different spellings

  1. Three spellings of the same number: decimal 75, octal 0113, hex 0x4B. Inside the computer all three become the same bits.
  2. All print 75. By default cout always shows numbers in decimal, whatever way you wrote them.
  3. Manipulators. oct, hex, dec change how cout prints: 75 in octal is 113, in hex is 4b, and dec switches back to decimal.
  4. The trap. 010 starts with 0, so it is octal: 1×8 + 0 = 8.

e means “move the dot”: e3 → 3 places right, e-2 → 2 places left

Why does 3.0 print as 3? cout drops trailing zeros. Why is 7 / 2 equal to 3 but 7 / 2.0 equal to 3.5? Two ints give an int answer (the fraction is thrown away); one decimal makes the whole answer decimal.

Character constants

One character in single quotes

'A'   '7'   '$'. Special characters use a backslash — they are called escape sequences.

CodeMeaningCodeMeaning
'\n'new line'\\'a backslash
'\t'tab (a wide jump)'\''a single quote
'\0'NULL (the end-of-string marker)'\"'a double quote
'\a'beep (alert)'\b'backspace
Why escape?

A quote mark normally ends the text. To print a quote inside text, put a backslash before it: "She said \"Hi\"". The backslash means “treat the next character specially”.

String constants

Text in double quotes has a hidden last character

The compiler secretly adds a NULL character '\0' at the end of every string, to mark where the text stops.

"Hello"Hello\0→ 6 bytes, not 5
Single quote = Single letter  |  Double quote = Dozens of letters

'A' is one char (1 byte). "A" is a string (2 bytes: A and \0).

See it work

Escapes and string size

  1. \" and \n. \" prints a real double quote inside the text. \n at the end moves to a new line (same effect as endl).
  2. \\ prints one backslash. To show C:\Users you must write each backslash twice, because a single \ starts an escape.
  3. sizeof a string. "Hi" is H + i + \0 = 3 bytes. "Hello" is 5 letters + \0 = 6 bytes.
Defined constants

Give a value a name once, use it everywhere

Instead of typing 3.14 in fifty places, name it. If the value ever changes, you edit one line.

  1. #define PI 3.14 — a preprocessor instruction. Before compiling, every PI in the file is replaced by the text 3.14. No =, no ;, no data type.
  2. const int RADIUS = 5; — a real variable with a type, but marked read-only. Writing RADIUS = 6; later would be a compile error.
  3. Using them. The compiler sees 3.14 * 5 * 5 = 78.5.

Trap

#define PI 3.14; (with a semicolon) pastes 3.14; everywhere, so 2 * PI * r becomes 2 * 3.14; * r → compile error.

Enumerations

enum: names for a family of constants

Picture it

Days of the week. Instead of remembering “Monday is 0, Tuesday is 1…”, you write MON, TUE, WED. The computer numbers them for you.

  1. Auto-numbering. MON is 0, TUE 1, WED 2, THU 3, FRI 4. It starts at 0 and adds 1 each time.
  2. Custom numbers. LOW = 10 sets 10. MEDIUM has no number, so it continues: 10 + 1 = 11. HIGH = 50 sets 50.
  3. Using it. today is a variable of type Day, set to WED. Printing shows the number behind the name: 0, 2, 4.
Trick

First name = 0. Each next name = previous + 1, unless you write =.

A Day variable can only hold Day names: today = 3; is an error in C++. (Modern C++ also has enum class, which Turbo C++ does not.)

Lesson 3 recap

What we learned

✅ Variables

  • Named locker: declare → initialise → assign.
  • Names: L-U-D, no keywords, case-sensitive.

✅ Constants

  • Integer: 75, octal 0113, hex 0x4B.
  • Float: 3.14, 2.5e3. Char 'A', string "A" (+ \0).
  • #define PI 3.14 (no ;), const, enum (counts from 0).
