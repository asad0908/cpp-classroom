Naming rules

Which declaration is INVALID?

  • int 2x;

  • char grade1;
  • double Total;
A name cannot start with a digit. _rate, grade1 and Total all follow the L-U-D rule.

Octal and hex

cout << 0x1A + 010; prints…

  • 26
  • 34
  • 18
  • 36
0x1A = 26 (hex). 010 = 8 (octal). 26 + 8 = 34.

Round 1 · 4 of 11 · Lesson 7

Precedence

What is 2 + 3 * 4 % 5 ?

  • 4
  • 0
  • 7
  • 9
* and % tie (left to right): (3 * 4) % 5 = 12 % 5 = 2. Then 2 + 2 = 4.
Round 1 · 5 of 11 · Lesson 5

Post-decrement

int i = 4; int j = i-- - 1; What is j?

  • 2
  • 3
  • 4
  • 5
Postfix: use first. j = 4 − 1 = 3, and only then i becomes 3.
Round 1 · 6 of 11 · Lesson 5

Logical hierarchy

cout << (!5 || 0 && 1); prints…

  • 1
  • 0
  • 5
  • Error
!5 = 0. Then 0 && 1 = 0 (AND before OR). Finally 0 || 0 = 0.
Round 1 · 7 of 11 · Lesson 5

Shorthand trap

int x = 10; x /= 3 + 2; What is x?

  • 3
  • 2
  • 5
  • 8
The whole right side first: x = 10 / (3 + 2) = 10 / 5 = 2.
Round 1 · 8 of 11 · Lesson 6

XOR

What is 12 ^ 5 ? (12 = 1100, 5 = 0101)

  • 9
  • 13
  • 4
  • 17
XOR gives 1 where bits differ: 1100 ^ 0101 = 1001 = 9.

Shift

What is 3 << 3 ?

  • 9
  • 24
  • 12
  • 6
Each left shift doubles: 3 × 23 = 3 × 8 = 24.
Round 1 · 10 of 11 · Lesson 8

Scope

int x = 10; { int x = 20; x++; } cout << x; prints…

  • 10
  • 11
  • 20
  • 21
The x++ changed the inner x, which dies at the closing brace. The outer x is still 10.
Round 1 · 11 of 11 · Lesson 8

Casting

cout << (int)'A' + 1.5; prints…

  • 66
  • 66.5
  • 65.5
  • B
The cast binds first: (int)'A' = 65. Then 65 + 1.5 = 66.5.

Find the output

Seven programs. For each: trace it on paper, then press ▶ Run to see what a real compiler prints.

Tracing tip

Make a small table with one column per variable. Update it after every line. That is exactly what the compiler’s memory does.

Round 2 · Program 1 of 7

Increment and decrement

  1. Start: a = 4, b = 3.
  2. Postfix a++ uses 4 (then a becomes 5). Prefix --b makes b = 2 first, then uses 2. So c = 4 × 2 + 2 = 10.
  3. Print: a = 5, b = 2, c = 10.
Round 2 · Program 2 of 7

Shorthand and the conditional operator

  1. x %= y → x = 6 % 4 = 2.
  2. y <<= 2 → y = 4 << 2 = 4 × 4 = 16.
  3. Ternary: is x > 1? 2 > 1 is true, so z takes the first value, y = 16.
  4. Print: 2 16 16.
Round 2 · Program 3 of 7

Logical and relational operators

  1. Four values printed side by side (no spaces):  (a && b) = 5 and 0 → 0  |  (a || b) = 5 or 0 → 1  |  !c = !3 → 0  |  (a > c && c > b) = 5 > 3 and 3 > 0 → 1. Together: 0101.
Round 2 · Program 4 of 7

Bitwise operators

  1. 10 = 1010, 6 = 0110. AND: 0010 = 2. OR: 1110 = 14. XOR: 1100 = 12.
  2. ~10 = −(10 + 1) = −11. 10 << 1 = 20. 6 >> 1 = 3.
Round 2 · Program 5 of 7

Scope and casting together

  1. Inside the block, n is 2 (it hides the outer n = 7). (float)n / 4 = 2.0 / 4 = 0.5.
  2. Outside, n is 7 again. n / 2 is int division = 3. (float)n / 2 = 7.0 / 2 = 3.5.
Round 2 · Program 6 of 7

Precedence and associativity

  1. r: 3 * 4 % 5 ties, left first: (3*4) % 5 = 12 % 5 = 2. Then 2 + 2 − 1 = 3.
  2. s: left to right: (10 − 4) − 3 = 6 − 3 = 3.
  3. t: level order: * first → 6; then > → 6 > 5 = 1; then == → 1 == 1 = 1.
Round 2 · Program 7 of 7

Enums and number systems

  1. enum: A = 3, B continues → 4, C = 10, D continues → 11.
  2. Print: 3 4 10 11.
  3. 011 is octal = 9. 0x10 is hex = 16. So 9 + 16 + 5 = 30.

Round 3 · the referee

Compare with the real compiler

  1. 1 and 2: 18 and 8. Same-level operators go left to right: 20 / 5 * 2 = (20/5) * 2 = 8.
  2. 3: 1. ((3+4) > 5) && ((10%3) == 1) = 1 && 1.
  3. 4 and 5: 10 and 2. + outranks <<; unary ! outranks +.
  4. 6: 3. AND before OR: 1 | (2 & 3) = 1 | 2.
  5. 7: 0 — the famous trap! == outranks &: ((1+2) == 3) & 4 = 1 & 4 = 0.
  6. 8: 4. (7 − (2*3)) + (8%5) = 1 + 3.

For any other expression, use the Expression solver in Lesson 7 — it shows each step.
