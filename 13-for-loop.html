The for Loop & Nested Loops

Computers are fast and never bored. A loop lets one short piece of code do a job a thousand times. We start with the loop made for counting.

By the end of this lesson you can
  • name the four parts of a loop and read a for header: for (init; condition; update)
  • write the sum of the first 10 numbers and trace it round by round
  • put a loop inside a loop to print a count matrix
The big idea

A loop repeats statements while a condition is true

Picture it

Your teacher says: “Write I will not talk in class 100 times.” You do not invent 100 different sentences. You follow one rule: start at 1, write, count up, stop after 100. A loop is that rule written for the computer.

1 · Initialise

Where does the counting start?

i = 1

2 · Condition

Keep going while this is true.

i <= 10

3 · Body

The work to repeat.

sum = sum + i;

4 · Update

Move towards the end.

i++

Forget the update and the loop never ends.
The family

C++ has three loop statements

🔢

for

Best when you know how many times: “do it 10 times”. All four parts sit in one line. This lesson.

❓

while

Best when you do not know how many times: “keep going until the user types 0”. Lesson 14.

🔄

do-while

Like while, but the body runs at least once before the first test. Lesson 15.

Syntax

The for header holds three of the four parts

The order of events

1. Initialisation runs once, at the start.

2. Condition is tested. False? The loop is over.

3. True? The body runs.

4. Update runs, then back to step 2.

See it work

Five rounds, counted

  1. The counter i is declared. It has no value yet.
  2. The header controls everything. i = 1 runs once. Then i <= 5 is tested before every round, and i++ runs after every round.
  3. The body is the repeated work: it prints the current round number.
  4. After the loop, i is 6, not 5. The loop only stopped when the test 6 <= 5 failed, so the counter had already moved past the end.

Practice program

Sum of the first 10 numbers: 1 + 2 + … + 10

Picture it

A piggy bank that starts empty. On round 1 you drop in 1 rupee, on round 2 you drop in 2, and so on. The total in the bank is the sum. A variable that collects a running total is called an accumulator.

  1. Empty the piggy bank first: sum = 0. Without this the bank would start with garbage and the answer would be wrong.
  2. i counts 1, 2, 3, … 10.
  3. Drop i into the bank: sum = sum + i means “take the old sum, add i, store it back”.
  4. Print the total after the loop. Printing inside the body would show every partial total. 1 + 2 + … + 10 = 55.

A famous shortcut

The young mathematician Gauss noticed 1 + 10 = 11, 2 + 9 = 11, … five pairs, so the sum is 5 × 11 = 55. In general the sum of the first n numbers is n * (n + 1) / 2. The loop does it the slow, general way, and works for any rule, not just consecutive numbers.

Link to Lesson 8

A counter declared inside the header is local to the loop

  1. int i is declared in the header. It is created when the loop starts and is destroyed when the loop ends. This is local scope from Lesson 8, with the loop’s braces as the block.
  2. After the loop writing cout << i; would be an error: i does not exist any more.
Turbo C++

Older compilers such as Turbo C++ treat the scope of such a counter differently. So in class we declare int i; before the loop, which behaves the same everywhere.

Classic traps

A stray ; and the off-by-one

  1. The ; is the whole body. The loop spins three times doing nothing, just like the stray semicolon after an if in Lesson 10.
  2. This line is outside the loop, so “Hi” prints once, not three times.
Off-by-one

How many times does for (i = 0; i <= 5; i++) run? Six (0, 1, 2, 3, 4, 5), not five. When counting from 0, use <. When counting from 1, use <=.

A loop inside a loop

Nested loops: the inner loop finishes completely for every round of the outer

Picture it

A clock. The hour hand moves one step, and during that time the minute hand goes round all 60 minutes. Then the hour hand moves again and the minute hand starts over. Hours are the outer loop; minutes are the inner loop.

Outer loop → rows

Controls how many lines we print. It moves on only when the inner loop is completely done.

Inner loop → columns

Controls how many items on one line. It restarts from the beginning every time the outer loop moves on.

Total inner rounds = outer rounds × inner rounds.
See it work

3 rows, 4 columns: print the column number

  1. The outer loop (i) chooses the row: 1, 2, 3.
  2. The inner loop (j) walks across the row: 1, 2, 3, 4. Every time we start a new row, j = 1 runs again, so j restarts.
  3. Print one number and a space, staying on the same line.
  4. The inner loop has finished, so end the line. Only now does the outer loop move to the next row.

Practice program

A count matrix: numbers 1 to 9 in a 3 × 3 grid

  1. A separate counter count, starting at 1. It is not reset when a row ends, so it keeps counting across the rows.
  2. Same two loops as before: 3 rows, 3 columns.
  3. Print the counter, then add 1. It runs 9 times in total, printing 1 to 9.
  4. End each row after its three numbers.
Without a counter

You can also work the number out from the loop variables: cout << (i - 1) * 3 + j << " "; gives the same grid. Try it for row 2, column 3: (2 − 1) × 3 + 3 = 6.

Bonus pattern

When the inner limit depends on the outer loop

  1. The inner test is j <= i, not a fixed number. In row 1 the inner loop runs once, in row 2 twice, in row 3 three times…
  2. One star per round of the inner loop, so row i has i stars.

Quick check — 3 of 5

for (i = 10; i > 0; i -= 3) cout << i << " "; What is printed?

  • 10 7 4
  • 10 7 4 1
  • 10 7 4 1 -2
  • 7 4 1
10, 7, 4, 1 are all above 0, so they print. Then i becomes −2, and -2 > 0 is false: 10 7 4 1.
Check yourself

Quick check — 4 of 5

int sum; for (i = 1; i <= 3; i++) sum = sum + i; What is wrong?

  • Nothing, it prints 6
  • sum was never set to 0, so it starts as garbage
  • The loop runs 4 times
  • sum must be a float
A local variable starts with a garbage value (Lesson 8). An accumulator must be set to 0 before the loop: int sum = 0;.
Check yourself

Quick check — 5 of 5

for (i = 1; i <= 2; i++) for (j = 1; j <= 3; j++) cout << "*"; How many stars are printed?

  • 5
  • 6
  • 8
  • 3
The inner loop prints 3 stars, and it runs once for each of the 2 outer rounds: 2 × 3 = 6.
Lesson 13 recap

What we learned

✅ The for loop

  • Four parts: initialise, condition, body, update. for (init; cond; update)
  • Init runs once; the test runs one more time than the body.
  • Sum of 10: sum = 0 first, then sum = sum + i inside, print after the loop.
  • Traps: stray ; after the header, and off-by-one.

✅ Nested loops

  • The inner loop finishes completely for each round of the outer loop, and restarts each time.
  • Outer = rows, inner = columns. Total = outer × inner.
  • Count matrix: a separate count that is not reset between rows.
