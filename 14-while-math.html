The while Loop & the Math Library

The for loop is perfect when we know the count. But what if we only know when to stop? That is the job of while. Then we borrow ready-made maths functions such as sqrt.

By the end of this lesson you can
  • write a while loop and move the four loop parts to the right places
  • redo the sum of 10 with while, and loop until the user types a stopping value
  • use <cmath> functions such as sqrt() and pow() inside a loop
Loop · test first

while: keep repeating as long as the condition is true

Picture it

“While there is water in the bucket, keep pouring.” You look in the bucket first. If it is already empty, you do not pour even once.

Your job

A while header holds only the condition. You must write the initialisation before the loop and the update inside the body yourself.

Same job, different loop

Sum of the first 10 numbers, now with while

  1. Initialisation happens here, before the loop: i = 1 and sum = 0.
  2. The header is only the test. Before every round: is i <= 10?
  3. The work: add i into the accumulator.
  4. The update is the last line of the body. If you forget it, i never changes and the loop never ends.
  5. After the loop: print 55, exactly the same answer as the for version.

Where while shines

Add numbers until the user types 0

Picture it

A cashier scans items until the customer says “that’s all”. Nobody knows in advance how many items there will be. A special value that means “stop” (here 0) is called a sentinel.

  1. Read the first number before the loop (5). Without this the test below would look at an empty locker.
  2. The test: is n different from 0? 5 is, so go in.
  3. Add it, then read the next number. The cin is the update: it changes n, so the test eventually sees the 0.
  4. The rounds: 5, 8, 2 are added. When cin reads 0, the test 0 != 0 is false and the loop ends.
  5. Print 15. If the very first number were 0, the body would run zero times and the output would be Total = 0. A while loop tests before the first round.
Ready-made functions

The math library: #include <cmath>

A function is a named mini-program. You give it a value in ( ), and it hands back an answer.

Header names

Modern C++: #include <cmath>
Turbo C++: #include <math.h>

Good habit

These functions work with decimals (double). Write 2.0 rather than 2 to stay safe on every compiler. There are more too: sin, cos, log, exp…

See it work

Five functions, five answers

  1. The new line: <cmath> brings in the maths functions. Without it, sqrt is “not declared”.
  2. Calling a function means writing its name with the value in brackets. The call is replaced by its answer, so cout << sqrt(49.0) prints 7.
  3. fabs drops the minus sign: 7.5.
  4. ceil and floor give whole numbers: 5 and 4. Notice the results print without .0.
Practice program

Square root of a number the user types

  1. A double variable, so the user may type decimals such as 2.25.
  2. Guard first! There is no real square root of a negative number. We use the if from Lesson 10 to check before calling the function.
  3. The call: sqrt(n) becomes 7, and cout prints it.
  4. Otherwise we print a friendly message instead of a strange “nan” (not a number) result.
Loops and functions together

A table of square roots: 1 to 10

  1. The standard while pattern: start at 1, test i <= 10, update with i++.
  2. The body calls sqrt(i) on a different value each round. An int is quietly converted to double (Lesson 8).
  3. Perfect squares (1, 4, 9) print as whole numbers. The others are endless decimals, and cout shows only the first 6 significant digits by default: 1.41421, not 1.41421356…

A while loop tests before the first round. 5 < 3 is false straight away, so the body never runs: nothing.

Lesson 14 recap

What we learned

✅ The while loop

  • while (condition) { body } tests first, so the body may run zero times.
  • Initialise before the loop; update inside the body.
  • Use for for a known count and while for “until something happens”, such as a sentinel value.

✅ The math library

  • #include <cmath> (<math.h> in Turbo C++).
  • sqrt, pow, fabs, ceil, floor: a call is replaced by its answer.
  • Check n >= 0 before sqrt(n). cout shows 6 significant digits by default.
