# C++ Classroom

Slide-style lessons for Class 11, Introduction to C++ (Parts 1 and 2). Every program is shown in Turbo C++ and Modern C++.

Live site: https://asad0908.github.io/cpp-classroom/

Plain HTML, CSS and JavaScript. No build step. Open `index.html` in a browser, or serve the folder with any static host.

Lessons: first program, data types, variables and constants, tokens and preprocessor, operators, bitwise and I/O operators, the operator table, scope and casting, exam practice.

Part 2, flow of control: if and if-else, nested if and the else-if ladder, switch and goto, the for loop and nested loops, the while loop and the math library, do-while with break, continue, infinite loops and exit(0).
